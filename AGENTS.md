# AGENTS.md

## Project Instructions

- Gunakan TypeScript untuk semua kode aplikasi.
- Prioritaskan Next.js App Router dan SSR.
- Gunakan Bun untuk install dependency, menjalankan dev server, build, dan start.
- Gunakan Biome untuk formatting dan linting.
- Gunakan Tailwind CSS untuk styling komponen UI.
- Gunakan TanStack Query untuk state server dan data fetching.
- Gunakan React Hook Form untuk form input dan Zod untuk validasi skema.
- Gunakan Recharts untuk visualisasi data.
- Gunakan PostgreSQL sebagai database utama.
- Gunakan Supabase sebagai backend platform dan integrasi data.
- Gunakan Drizzle sebagai ORM.
- Untuk fitur AI, integrasikan melalui OpenRouter API atau LLM API.
- Untuk tracking mobile, rujuk Android Usage Stats API sebagai sumber data.

## Working Rules

- Jaga perubahan tetap kecil dan terarah.
- Jangan mengubah konfigurasi atau file yang tidak relevan dengan tugas.
- Jika menambah fitur, pertahankan pola kode yang sudah ada di repository.
- Bila membuat atau mengubah dokumentasi, sinkronkan isi README dengan instruksi proyek.
