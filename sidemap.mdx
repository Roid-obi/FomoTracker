📱 APPLICATION

🏠 Beranda — /dashboard
Tujuan:
Memberikan gambaran kondisi penggunaan hari ini
secara sekilas dan mudah dipahami.
Tidak ada angka teknis, tidak ada istilah asing.

Periode semua data di halaman ini: HARI INI

/dashboard
│
├── Sapaan Personal & Tanggal
│ └── "Halo, Budi! — Rabu, 4 Juni 2026"
│
├── Status Hari Ini ← ELEMEN UTAMA, TAMPIL BESAR
│ Periode : Hari ini
│ Tampilan: Satu status dengan ilustrasi/emoji besar
│ │
│ ├── 😊 Hari yang Baik
│ │ "Penggunaan HP-mu hari ini terkontrol."
│ ├── 😐 Perlu Diperhatikan
│ │ "Ada beberapa kebiasaan yang terdeteksi hari ini."
│ └── 😟 Hari yang Berat
│ "Banyak kebiasaan bermasalah terdeteksi hari ini."
│
├── Ringkasan Singkat ← 2–3 kalimat natural, bukan angka
│ Periode : Hari ini
│ Contoh : "Kamu sudah pakai HP selama 3 jam hari ini.
│ TikTok paling banyak kamu buka.
│ Belum ada kebiasaan bermasalah yang terdeteksi."
│
├── Aktivitas Hari Ini
│ Periode : Hari ini (00:00 – sekarang)
│ Tampilan: Stacked bar chart per jam
│ │
│ ├── Sumbu X: Jam (00.00 – 23.00)
│ ├── Sumbu Y: Menit penggunaan
│ └── Warna berbeda per aplikasi + keterangan (legend)
│
├── Kebiasaan yang Terdeteksi Hari Ini
│ Periode : Hari ini
│ Tampilan: Hanya muncul jika terdeteksi.
│ Jika tidak ada → tampilkan
│ "Tidak ada kebiasaan bermasalah hari ini 👍"
│ │
│ ├── 📱 Terlalu lama main HP
│ │ └── "Terdeteksi X jam Y menit hari ini"
│ ├── 🔄 Sering buka-tutup aplikasi
│ │ └── "Dibuka X kali hari ini"
│ ├── 🌙 Main HP waktu harusnya tidur
│ │ └── "Terdeteksi X menit tadi malam"
│ ├── ⏳ Nonstop tanpa istirahat
│ │ └── "Sesi terpanjang X menit tanpa jeda"
│ └── 💼 Main HP saat jam belajar/kerja
│ └── "Terdeteksi X menit saat jam produktif"
│
└── Cuplikan Insight Terakhir
Periode : Insight mingguan terakhir yang tersedia
Tampilan: 1–2 kalimat kutipan dari insight terakhir
└── Tombol "Baca Selengkapnya" → /insight

📊 Statistik — /statistik
Tujuan:
Melihat pola penggunaan dengan bahasa dan visualisasi
yang mudah dipahami. Tidak ada istilah teknis.
Tidak ada narasi AI di halaman ini.

Filter Periode (tampil sebagai 2 tombol di atas halaman)
├── Minggu Ini ← default
└── Minggu Lalu

Catatan periode:
Minggu Ini = 7 hari terakhir (rolling dari hari ini)
Minggu Lalu = 7 hari sebelumnya

/statistik
│
├── Berapa Lama Kamu Pakai HP?
│ │
│ ├── Total minggu ini: "X jam Y menit"
│ ├── Rata-rata per hari: "X jam Y menit per hari"
│ └── Dibanding minggu lalu:
│ ↑ "X menit lebih lama dari minggu lalu" (merah)
│ ↓ "X menit lebih singkat dari minggu lalu" (hijau)
│ → "Sama seperti minggu lalu" (abu)
│
├── Aplikasi Apa yang Paling Banyak Kamu Buka?
│ │
│ ├── Bar chart horizontal per aplikasi
│ │ (nama aplikasi + durasi dalam jam/menit)
│ └── Tanpa angka persentase
│
├── Jam Berapa Kamu Paling Sering Online?
│ │
│ ├── Heatmap sederhana (sumbu X = jam, sumbu Y = hari)
│ ├── Highlight otomatis warna berbeda:
│ │ ├── 🌙 Jam tidur → warna merah muda
│ │ └── 💼 Jam belajar/kerja → warna kuning
│ └── Keterangan warna di bawah chart
│
└── Kebiasaan yang Sering Muncul Minggu Ini
│
├── 📱 Terlalu lama main HP → Muncul X dari 7 hari
├── 🔄 Sering buka-tutup app → Muncul X dari 7 hari
├── 🌙 Main HP waktu tidur → Muncul X dari 7 hari
├── ⏳ Nonstop tanpa jeda → Muncul X dari 7 hari
└── 💼 Distraksi jam produktif → Muncul X dari 7 hari

    Tampilan: progress bar sederhana
    Contoh  : "🌙 Main HP waktu tidur
               ████████░░  Muncul 5 dari 7 hari"

💬 Insight — /insight
Tujuan:
Tempat AI memberikan analisis dan saran tentang
kebiasaan digital user. Bahasa seperti teman,
bukan laporan teknis.

Kapan insight dibuat:
Setiap 7 hari sejak hari pertama user memiliki data.
Jadwal tiap user berbeda tergantung kapan mulai pakai.
User tidak perlu tahu detail ini —
cukup tampilkan tanggal periode insight.

/insight
│
├── Jika insight belum tersedia (user baru)
│ │
│ └── Card informatif:
│ ┌─────────────────────────────────────┐
│ │ 🔍 Insight pertamamu sedang │
│ │ disiapkan! │
│ │ │
│ │ Kami butuh beberapa hari untuk │
│ │ mengenali pola penggunaan HP-mu. │
│ │ │
│ │ ████████░░░░░ 5 dari 7 hari │
│ └─────────────────────────────────────┘
│
└── Jika insight sudah tersedia
│
├── Insight Minggu Ini
│ │
│ ├── Periode: "2–8 Juni 2026"
│ │
│ ├── Kondisi Minggu Ini ← label + 1 kalimat
│ │ ├── 😊 "Minggu yang baik!"
│ │ │ "Kamu berhasil menjaga penggunaan HP
│ │ │ tetap terkontrol minggu ini."
│ │ ├── 😐 "Minggu yang cukup padat secara digital."
│ │ │ "Ada beberapa kebiasaan yang perlu
│ │ │ kamu perhatikan minggu ini."
│ │ └── 😟 "Minggu yang cukup berat."
│ │ "Penggunaan HP minggu ini cukup
│ │ mengkhawatirkan."
│ │
│ ├── Yang Sudah Kamu Lakukan dengan Baik 👍
│ │ └── Narasi AI 2–3 kalimat positif
│ │ Contoh: "Kamu berhasil mengurangi penggunaan
│ │ TikTok di jam belajar dibanding
│ │ minggu lalu. Pertahankan!"
│ │
│ ├── Yang Perlu Kamu Perhatikan ⚠️
│ │ └── Narasi AI 2–3 kalimat, tanpa menghakimi
│ │ Contoh: "Kamu cukup sering buka HP
│ │ setelah jam 23.00. Ini bisa
│ │ memengaruhi kualitas tidurmu."
│ │
│ ├── Kata AI untuk Minggu Ini 🤖
│ │ └── Paragraf analisis AI, bahasa santai
│ │
│ └── Tips untuk Minggu Depan 💡
│ └── 3 saran konkret, bahasa natural
│ Contoh:
│ "Coba taruh HP di luar kamar saat tidur"
│ "Batasi buka TikTok maksimal 2x sehari"
│ "Aktifkan mode fokus saat jam belajar"
│
└── Insight Sebelumnya
│
├── Filter Bulan
│
└── Daftar card insight lama (terbaru di atas)
Tiap card menampilkan:
├── Periode (contoh: "26 Mei – 1 Juni 2026")
├── Kondisi minggu tersebut (emoji + label)
└── Tombol Baca → /insight/[id]
