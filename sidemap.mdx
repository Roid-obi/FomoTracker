### 🏠 Beranda — `/dashboard`

```
Tujuan:
Gambaran kondisi penggunaan media sosial hari ini.
Semua data di halaman ini = HARI INI (00:00 – sekarang).
Tidak ada angka skor, tidak ada istilah teknis.

/dashboard
│
├── Navbar Atas
│   ├── Logo FomoTracker
│   └── Ikon Lonceng 🔔 → /notifications
│
├── Sapaan & Tanggal
│   └── "Halo, Budi! — Rabu, 4 Juni 2026"
│
├── Status Hari Ini  ← ELEMEN UTAMA, TAMPIL PALING BESAR
│   Sumber : behaviour_scores hari ini
│   │
│   ├── 😊 Hari yang Baik
│   │   └── "Penggunaan HP-mu hari ini terkontrol."
│   ├── 😐 Perlu Diperhatikan
│   │   └── "Ada beberapa kebiasaan yang
│   │        terdeteksi hari ini."
│   └── 😟 Hari yang Berat
│       └── "Banyak kebiasaan bermasalah
│            terdeteksi hari ini."
│
│   Jika belum ada data hari ini:
│   └── "Belum ada aktivitas yang terdeteksi hari ini.
│        Pastikan Android App atau Browser Extension
│        sudah terhubung."
│
├── Ringkasan Singkat
│   Sumber : daily_stats + activity_log hari ini
│   Tampilan: 2–3 kalimat natural tanpa angka teknis
│   Contoh : "Kamu sudah pakai HP selama 3 jam hari ini.
│             TikTok paling banyak kamu buka.
│             Belum ada kebiasaan bermasalah terdeteksi."
│
├── Aktivitas Hari Ini
│   Judul  : "Penggunaan per Jam Hari Ini"
│   Sumber : activity_log hari ini, dikelompokkan per jam
│   Tampilan: Stacked bar chart
│   │
│   ├── Sumbu X : Jam 00.00 – 23.00
│   ├── Sumbu Y : Menit penggunaan
│   ├── Warna   : Berbeda per aplikasi
│   └── Legend  : Nama aplikasi + warna
│
├── Kebiasaan yang Terdeteksi Hari Ini
│   Sumber : behaviour_scores flags hari ini
│   │
│   Jika tidak ada kebiasaan terdeteksi:
│   └── ✅ "Tidak ada kebiasaan bermasalah hari ini!"
│
│   Jika ada, tampilkan hanya yang terdeteksi:
│   ├── 📱 Terlalu lama main HP
│   │   └── "Sudah X jam Y menit hari ini"
│   ├── 🔄 Sering buka-tutup aplikasi
│   │   └── "Dibuka X kali hari ini"
│   ├── 🌙 Main HP waktu harusnya tidur
│   │   └── "X menit terdeteksi di jam tidur"
│   ├── ⏳ Nonstop tanpa istirahat
│   │   └── "Sesi terpanjang X menit tanpa jeda"
│   └── 💼 Main HP saat jam belajar/kerja
│       └── "X menit terdeteksi di jam produktif"
│
└── Cuplikan Insight Terakhir
    Sumber : insight mingguan terakhir yang tersedia
    Tampilan: Card dengan 1–2 kalimat kutipan
    │
    ├── Periode insight (contoh: "1–7 Juni 2026")
    ├── Kutipan singkat dari insight
    └── Tombol "Baca Selengkapnya" → /insight
```

### 📊 Statistik — `/statistik`

```
Tujuan:
Melihat pola penggunaan mingguan dengan bahasa
dan visualisasi yang mudah dipahami.
Tidak ada narasi AI, tidak ada skor teknis.

/statistik
│
├── Filter Periode (2 tombol di atas halaman)
│   ├── Minggu Ini   ← default
│   │   = Senin minggu ini s/d hari ini
│   └── Minggu Lalu
│       = Senin s/d Minggu minggu lalu (7 hari penuh)
│
│   Jika hari ini Senin dan memilih "Minggu Ini":
│   └── Tampilkan keterangan:
│       "Minggu ini baru dimulai hari ini."
│
├── Berapa Lama Kamu Pakai HP?
│   Sumber : SUM daily_stats.total_duration_seconds
│   │
│   ├── Total: "X jam Y menit"
│   ├── Rata-rata per hari: "X jam Y menit per hari"
│   └── Perbandingan vs minggu lalu:
│       ↑ "X menit lebih lama dari minggu lalu" (merah)
│       ↓ "X menit lebih singkat dari minggu lalu" (hijau)
│       → "Sama seperti minggu lalu" (abu-abu)
│
│   Tidak muncul jika memilih "Minggu Lalu"
│   (tidak ada pembanding)
│
├── Grafik Penggunaan Harian
│   Sumber : daily_stats per hari dalam periode
│   Tampilan: Bar chart
│   │
│   ├── Sumbu X : Hari (Sen, Sel, Rab, dst.)
│   ├── Sumbu Y : Jam penggunaan
│   └── Warna berbeda per aplikasi (stacked)
│
├── Aplikasi Apa yang Paling Banyak Kamu Buka?
│   Sumber : SUM daily_stats per app_id dalam periode
│   Tampilan: Bar chart horizontal
│   │
│   ├── Diurutkan dari terbanyak
│   ├── Nama aplikasi + ikon + durasi (jam/menit)
│   └── Tanpa angka persentase
│
├── Jam Berapa Kamu Paling Sering Online?
│   Sumber : Agregasi activity_log per jam dalam periode
│   Tampilan: Heatmap (sumbu X = jam, sumbu Y = hari)
│   │
│   ├── Warna makin gelap = makin lama online
│   ├── Highlight 🌙 jam tidur (warna merah muda)
│   ├── Highlight 💼 jam belajar/kerja (warna kuning)
│   └── Keterangan warna di bawah heatmap
│
└── Kebiasaan yang Sering Muncul Minggu Ini
    Sumber : COUNT flag = true per hari dalam periode
    Tampilan: List dengan progress bar
    │
    ├── 📱 Terlalu lama main HP
    │   └── Progress bar + "Muncul X dari Y hari"
    ├── 🔄 Sering buka-tutup aplikasi
    │   └── Progress bar + "Muncul X dari Y hari"
    ├── 🌙 Main HP waktu tidur
    │   └── Progress bar + "Muncul X dari Y hari"
    ├── ⏳ Nonstop tanpa jeda
    │   └── Progress bar + "Muncul X dari Y hari"
    └── 💼 Distraksi jam produktif
        └── Progress bar + "Muncul X dari Y hari"
```

### 💬 Insight — `/insight`

```
Tujuan:
Tempat AI memberikan analisis dan saran mingguan.
Satu-satunya halaman yang berisi narasi dari AI.
Bahasa santai seperti teman, bukan laporan teknis.

Sistem generate insight:
- Dibuat otomatis setiap Senin pukul 00:00
- Mencakup data Senin s/d Minggu minggu sebelumnya
- Setiap user mendapat insight bersamaan (bukan rolling)

/insight
│
├── Jika user baru (belum punya insight sama sekali)
│   └── Card informatif
│       ┌──────────────────────────────────────────┐
│       │ 🔍 Insight pertamamu sedang disiapkan!   │
│       │                                          │
│       │ Kami butuh data satu minggu penuh untuk  │
│       │ bisa mengenali pola penggunaan HP-mu.    │
│       │                                          │
│       │ Insight pertama akan muncul pada:        │
│       │ Senin, 9 Juni 2026                       │
│       │                                          │
│       │ Sementara itu, pantau aktivitas harianmu │
│       │ di halaman Beranda dan Statistik.        │
│       └──────────────────────────────────────────┘
│
└── Jika sudah ada insight
    │
    ├── ── Insight Minggu Ini ──
    │   │
    │   ├── Periode: "Senin 26 Mei – Minggu 1 Juni 2026"
    │   │
    │   ├── Kondisi Minggu Ini
    │   │   ├── 😊 Minggu yang Baik!
    │   │   ├── 😐 Minggu yang Cukup Padat
    │   │   └── 😟 Minggu yang Cukup Berat
    │   │   + 1 kalimat deskripsi
    │   │
    │   ├── Yang Sudah Kamu Lakukan dengan Baik 👍
    │   │   └── Narasi AI 2–3 kalimat positif
    │   │
    │   ├── Yang Perlu Kamu Perhatikan ⚠️
    │   │   └── Narasi AI 2–3 kalimat, tidak menghakimi
    │   │
    │   ├── Analisis Minggu Ini 🤖
    │   │   └── Paragraf analisis AI, bahasa santai
    │   │
    │   └── Tips untuk Minggu Depan 💡
    │       └── 3 saran konkret dan actionable
    │           Contoh:
    │           "Coba taruh HP di luar kamar saat tidur"
    │           "Batasi buka TikTok maksimal 2x sehari"
    │           "Aktifkan mode fokus saat jam belajar"
    │
    └── ── Insight Sebelumnya ──
        │
        ├── Filter Bulan
        │
        └── Daftar card insight lama (terbaru di atas)
            Tiap card:
            ├── Periode insight
            ├── Kondisi minggu (emoji + label)
            └── Tombol Baca → /insight/[id]


/insight/[id]
Detail Insight Minggu Tertentu
│
├── Periode Insight
├── Kondisi Minggu Itu (emoji + label + deskripsi)
├── Yang Sudah Dilakukan dengan Baik 👍
├── Yang Perlu Diperhatikan ⚠️
├── Analisis Minggu Itu 🤖
├── Tips yang Diberikan 💡
│
└── Dibanding Minggu Sebelumnya
    ├── Durasi pakai HP : ↑ naik / ↓ turun / → sama
    ├── Kebiasaan bermasalah : lebih banyak / lebih sedikit / sama
    └── Kondisi keseluruhan : Membaik / Memburuk / Stabil
```
